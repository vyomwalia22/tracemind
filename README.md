# TraceMind

**Ask about a wallet. Trace the evidence.**

TraceMind is an AI-powered onchain investigator that lets users ask natural-language questions about a wallet and receive an evidence-backed investigation report.

The current MVP focuses on **Aave V3 on Ethereum**. TraceMind retrieves structured onchain activity through The Graph, performs deterministic financial normalization and aggregation, builds traceable evidence records, and uses Claude to interpret the retrieved data.

## Live Demo

**Production:** https://tracemind-nine.vercel.app/

## Why TraceMind

Blockchain data is public, but understanding what actually happened is still difficult.

Transaction explorers and wallet dashboards expose raw activity, but users often have to manually connect transactions, calculate exposure, identify unusual patterns, and determine which records actually support a conclusion.

TraceMind turns that workflow into an investigation:

```text
Wallet + Question
       ↓
Live Onchain Data
       ↓
Deterministic Calculations
       ↓
Evidence Records
       ↓
AI Reasoning
       ↓
Investigation Report
```

The goal is simple:

> Ask about a wallet. Trace the evidence.

## How It Works

A user provides:

1. A wallet address
2. A natural-language investigation question

TraceMind then:

1. Retrieves relevant Aave V3 Ethereum activity using The Graph.
2. Normalizes token amounts using the retrieved token decimals.
3. Calculates deterministic aggregates for supply, borrow, repayment, and related activity.
4. Builds stable evidence records from the retrieved onchain data.
5. Sends the evidence and computed aggregates to Claude for investigation and interpretation.
6. Validates that findings reference actual retrieved evidence.
7. Presents the investigation as a structured report containing an assessment, findings, calculations, and onchain evidence.

## Why The Graph

The Graph is a core part of TraceMind's data layer.

TraceMind uses The Graph to retrieve structured Aave V3 Ethereum data rather than relying on manually indexed or mocked blockchain records.

The Graph integration provides:

* Structured onchain data access
* Aave V3 Ethereum activity retrieval
* Query-based investigation data
* Cursor-based pagination
* Evidence records derived from retrieved blockchain activity

This allows the investigation engine to work from live structured blockchain data.

### Investigation UI

Collects the wallet address and natural-language investigation question.

### Investigation API

Coordinates the investigation pipeline and returns a structured investigation result.

### The Graph

Retrieves structured Aave V3 Ethereum activity for the wallet.

### Deterministic Normalization

Token amounts are normalized server-side using the decimals associated with the retrieved assets. Raw base-unit values remain available for traceability.

### Deterministic Aggregates

Financial totals and related calculations are computed in application code rather than generated by the AI model.

### Evidence Builder

Transforms retrieved blockchain records into stable, traceable evidence records.

### Claude Investigation Engine

Claude interprets the retrieved evidence and deterministic calculations to produce an investigation report.

### Structured Report

The final result contains an executive assessment, findings, deterministic calculations, and the underlying evidence records supporting those findings.

## Evidence-First AI

TraceMind separates **facts from interpretation**.

The application does not ask the AI model to invent blockchain activity or independently calculate financial totals.

Instead:

* Onchain records are retrieved first.
* Token amounts are normalized server-side.
* Financial aggregates are calculated deterministically.
* Raw values remain available for traceability.
* Evidence records receive stable IDs.
* Claude receives retrieved evidence and computed aggregates.
* Findings reference evidence IDs.
* Unknown evidence references are rejected.
* Evidence completeness and truncation are surfaced to the investigation.

This creates a clear relationship between an AI conclusion and the underlying blockchain records.

## Deterministic Financial Data

Financial values are handled separately from AI reasoning.

TraceMind:

* Retrieves token decimals from the underlying data.
* Uses exact decimal-safe arithmetic.
* Preserves raw base-unit values.
* Produces normalized human-readable amounts.
* Calculates supply, borrow, repayment, and related aggregates in code.
* Keeps assets isolated when calculating their respective activity.

The AI model is given these computed values as facts to interpret rather than being responsible for recomputing them.

## Evidence Completeness & Pagination

TraceMind uses cursor-based pagination when retrieving investigation data.

The investigation tracks whether the retrieved evidence window is complete or truncated.

This matters because a limited evidence window must not be presented as complete wallet history.

Aggregates are calculated over the dataset that was actually retrieved, and the report can surface when the available evidence is incomplete.

## Getting Started

### Requirements

* Node.js 20.9 or newer
* A The Graph API key
* An Anthropic API key

### Installation

```bash
git clone https://github.com/vyomwalia22/tracemind.git
cd tracemind
npm install
```

### Environment Variables

Create a `.env.local` file in the project root.

```env
THE_GRAPH_API_KEY=your_graph_api_key
ANTHROPIC_API_KEY=your_anthropic_api_key
```

Never commit real API keys or secrets to the repository.

### Run the Development Server

```bash
npm run dev
```

Open:

```text
http://localhost:3000
```
